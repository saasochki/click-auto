# Открытые вопросы и риски

## Открытые вопросы

Все вопросы из research закрыты, решения внесены в остальные документы. Новые вопросы добавляем сюда таблицей «# · Вопрос · Откуда · Влияет на».

## Риски

| Риск | Последствие | Как снижаем |
| --- | --- | --- |
| Мало объявлений на старте | Покупатели не находят машин и уходят | Импорт с 999.md, makler.md и klaxon.md, бесплатное размещение |
| Продавец не хочет, чтобы его объявление было у нас | Жалоба, потеря доверия | Ссылка на источник, быстрое удаление по запросу автора |
| Источник блокирует парсер или меняет вёрстку | Импорт останавливается, объявления устаревают | Мониторинг импорта, скрытие объявлений, которые давно не обновлялись |
| Устаревшие импортированные объявления | Покупатель пишет по проданной машине и теряет доверие | Регулярная перепроверка, скрытие снятых с источника |
| Спам и мошенники в чате | Потеря доверия | Вход по коду, жалобы, блокировка, модерация |
| Письма с кодом попадают в спам или приходят с задержкой | Пользователь не может войти | Настроенный домен отправки (SPF, DKIM, DMARC), вход через Google как запасной путь. Spacemail — почтовый ящик, а не транзакционный сервис: следим за лимитами отправки и доставляемостью; если не хватит, меняем провайдера в конфигурации SMTP |
| Всё на одном VPS | Падение сервера останавливает весь сайт, данные можно потерять | Ежедневные бэкапы PostgreSQL и MinIO вне сервера, мониторинг доступности, инструкция по восстановлению |
| Без входа по телефону меньше доверия к продавцам | Больше фейковых объявлений | Модерация, жалобы; вернуться к входу по телефону на следующих этапах |
| Сделки уходят в мессенджеры | Не видим контакты и конверсию | Удобный чат, шаблоны, событие `contact_click` для звонков |
| Свой справочник марок и моделей неполный или с ошибками | Продавец не находит свою модель, фильтр теряет объявления | Вариант «Другая» в форме, модерация новых моделей, регулярное пополнение справочника по таким объявлениям |
