# Метрики

North Star — **число уникальных контактов покупателя с продавцом в неделю**: первое сообщение в чате по авто или нажатие «Позвонить». Это момент, ради которого платформой пользуются обе стороны. Метрика растёт, только если есть и предложение (объявления), и спрос (покупатели).

> Метрики в research не описаны. Ниже — предложение аналитика, которое нужно согласовать с командой.

## Воронка покупателя

1. Первый визит на сайт (по источнику: поиск, соцсети, прямой заход)
2. Регистрация (код подтверждён, ник выбран)
3. Просмотр ленты
4. Применение поиска или фильтра
5. Открытие страницы авто
6. Добавление в избранное
7. Контакт с продавцом (чат или звонок) — North Star

## Воронка продавца

1. Регистрация
2. Начало создания объявления
3. Публикация объявления
4. Первый входящий контакт
5. Скрытие или снятие авто (прокси продажи)

## KPI

| Группа | Метрика | Как считаем |
| --- | --- | --- |
| Предложение | Активные объявления | Опубликованы и не скрыты, на конец дня |
| Предложение | Новые объявления в неделю | Публикации за 7 дней |
| Предложение | Доля собственных объявлений | Объявления наших пользователей / все активные. Должна расти: импорт — временная подпорка |
| Импорт | Объявления по источникам, доля дублей, доля несопоставленных | По 999.md, makler.md, klaxon.md отдельно |
| Импорт | Переходы на источник | Клики «Источник» / просмотры импортированных карточек |
| Предложение | Доля объявлений с контактом за 7 дней | Объявления с ≥ 1 контактом / новые объявления |
| Спрос | DAU, WAU, MAU | Уникальные пользователи с любым событием |
| Трафик | Органический трафик | Визиты из поисковых систем, по типу страницы: каталог, авто, профиль |
| Трафик | Доля мобильного трафика | Визиты со смартфонов / все визиты |
| Сайт | Core Web Vitals | LCP, INP, CLS на мобильных, 75-й перцентиль |
| Спрос | Конверсия просмотр → контакт | Контакты / просмотры страниц авто |
| Вход | Конверсия регистрации | Подтверждённый код / начатая регистрация, по способу входа |
| Вход | Доля ошибок кода | Неверный код / попытки ввода |
| Вовлечение | Retention D1, D7, D30 | По когортам регистрации |
| Чат | Время до первого ответа продавца | Медиана, часы |
| Чат | Доля чатов с ответом | Чаты с ответом продавца / все чаты |
| Товары для авто | Активные объявления и контакты по товарам | Те же метрики, что для авто, с разрезом `listing_type` = goods и по категориям |
| Услуги | Активные объявления и контакты по услугам | То же, `listing_type` = service |
| Тиндер | Доля свайпов вправо | Вправо / все свайпы |
| Тиндер | Конверсия свайп → контакт | Контакты из свайпов / свайпы вправо |
| Качество | Жалобы на 1000 объявлений | Жалобы на объявления и сообщения |
| Модерация | Время обработки жалобы | Медиана от подачи до решения, часы |
| Модерация | Очередь ручной проверки импорта | Число несопоставленных объявлений на конец дня |
| Монетизация | Доля платных объявлений, ARPU | Не на первом этапе: после запуска закрепов и рекламы |

## События аналитики

События объявлений (`car_view`, `favorite_toggle`, `contact_click`, `listing_*`) несут параметр `listing_type`: car, goods или service. У товаров и услуг есть ещё параметр `category`.

| Событие | Ключевые параметры |
| --- | --- |
| `session_start` | `source`, `utm_*`, `device`: mobile / tablet / desktop |
| `auth_start` | `method`: email / google |
| `auth_code_submit` | `method`, `success` |
| `auth_username_set` | `attempts` |
| `feed_view` | `sort` |
| `search_submit` | `query`, `brand` |
| `filter_apply` | Список заполненных фильтров |
| `car_view` | `car_id`, `source`: feed / search / favorites / swipe / profile |
| `favorite_toggle` | `car_id`, `state`, `source` |
| `contact_click` | `car_id`, `type`: chat / call |
| `chat_message_send` | `chat_id`, `car_id`, `is_first` |
| `listing_create_start` / `listing_publish` | `car_id` |
| `listing_hide` / `listing_delete` | `car_id`, `days_live` |
| `swipe` | `car_id`, `direction` |
| `report_submit` | `target`: car / message / user |
