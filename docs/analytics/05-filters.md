## Зависимости фильтров

От марки зависят только модель и поколение. Остальные фильтры независимы: их значения не меняются от выбранной марки. Так устроены Авто.ру, Дром и 999.md — главный авто-классифайд Молдовы ([999.md](https://999.md/ru/list/transport/cars), [Дром](https://auto.drom.ru/toyota/camry/)).

Почему не делаем остальные фильтры зависимыми от марки: тогда нужен полный справочник комплектаций (какие двигатели, кузова, коробки бывают у каждой модели). На рынке ПМР и Молдовы много серых импортов и переделок, так что такой справочник будет неполным и спрячет реальные объявления.

### Каскад «Марка → Модель → Поколение»

```mermaid
flowchart LR
    Brand[Марка] -->|список моделей этой марки| Model[Модель]
    Model -->|список поколений модели| Gen[Поколение]
```

| Правило | MVP | Следующий этап |
| --- | --- | --- |
| Модель недоступна, пока не выбрана марка | Да | Да |
| Смена или сброс марки сбрасывает модель и поколение | Да | Да |
| Несколько пар «марка + модель» в одном поиске (например, Toyota Camry или Kia Optima) | Да, до 5 пар | Да |
| Исключение марки («кроме ВАЗ») | — | Да |
| Поколение: выбор по годам выпуска и фото кузова, как на Авто.ру | — | Да, нужен справочник поколений |
| В списке моделей видно число объявлений, модели без объявлений в конце списка | Да | Да |

### Другие зависимости

- **Вид топлива → объём двигателя.** Если выбрано только «Электричество», фильтр объёма двигателя скрывается: у электромобилей его нет.
- **Число объявлений в значениях.** В следующем этапе рядом со значениями фильтров (кузов, коробка, топливо) показывается, сколько объявлений найдётся с учётом уже выбранных условий. Значения с нулём становятся неактивными, но не скрываются.

### Форма создания объявления

- Марка и модель обязательны и выбираются из справочника каскадом. Если модели нет в справочнике, продавец выбирает «Другая» и вписывает название. Такие объявления проходят модерацию, а модель потом добавляется в справочник.
- Остальные параметры продавец заполняет вручную. Автоподстановка характеристик по поколению — следующий этап, вместе со справочником поколений.

## Товары для авто

Всё, что относится к автомобилю, кроме самих машин, лежит в одном разделе «Товары для авто». Категория — главный фильтр раздела: от неё зависят дополнительные фильтры. Дерево категорий и фильтры ниже утверждены.

### Категории

| Категория | Подкатегории |
| --- | --- |
| Запчасти | Двигатель, трансмиссия, подвеска и рулевое, тормоза, кузов, оптика, электрика, салон, охлаждение и отопление, выхлопная система |
| Шины | Летние, зимние, всесезонные |
| Диски | Литые, штампованные, кованые |
| Шины в сборе с дисками | — |
| Аудио и электроника | Магнитолы, акустика, видеорегистраторы, навигаторы, камеры, сигнализации |
| Аксессуары | Коврики, чехлы, багажники и боксы, фаркопы, прочее |
| Масла и автохимия | Моторные масла, трансмиссионные масла, жидкости, автокосметика |
| Инструменты и оборудование | Домкраты, компрессоры, пуско-зарядные устройства, наборы инструментов |

### Фильтры, зависящие от категории

| Категория | Дополнительные фильтры |
| --- | --- |
| Запчасти | Совместимость (марка, модель, год из справочника авто), номер детали (OEM), оригинал / аналог |
| Шины | Ширина, профиль, диаметр, сезон, шипы, количество в комплекте |
| Диски | Диаметр, ширина, сверловка (PCD), вылет (ET), тип диска, количество в комплекте |
| Шины в сборе с дисками | Фильтры шин и дисков вместе |
| Аудио и электроника, аксессуары | Совместимость с авто (необязательно) |
| Масла и автохимия, инструменты | Только общие фильтры |

Правила те же, что у каскада «марка → модель»: смена категории сбрасывает её дополнительные фильтры. Пока категория не выбрана, видны только общие фильтры.
