# Админка

Админка — отдельное приложение `apps/admin`: одностраничное приложение (SPA) для сотрудников. SEO и серверный рендеринг ей не нужны, поэтому это не Next.js, а Vite. Код не попадает в бандл сайта, а доступ можно закрыть на уровне сети. Функциональные требования — в [аналитике](../analytics/03-requirements.md#10-админка), API — в [гайдлайнах](../backend/04-api-guidelines.md#api-админки).

## Стек

| Слой | Технология | Почему |
| --- | --- | --- |
| Сборка | Vite 6, React 19, TypeScript | Быстрая сборка SPA, без SSR |
| Роутинг | TanStack Router | Типобезопасные маршруты и search-параметры для фильтров таблиц |
| API-клиент | orval + TanStack Query — как на сайте ([API-клиент](06-api-client.md)) | Отдельный конфиг orval только для тегов `admin-*` |
| Таблицы | TanStack Table | Сортировка, пагинация, выбор колонок, на серверных данных |
| Формы | React Hook Form + Zod из `packages/shared` | Те же правила, что на бэке |
| UI | Компоненты `packages/ui` (общие с сайтом) | Одна дизайн-система; админка использует плотный вариант |
| Графики (дашборд, следующий этап) | Recharts | |
| Тесты | Vitest, Testing Library, Playwright | |

Сайт и админка используют общий пакет `packages/ui` с компонентами и токенами.

## Конфиг orval для админки

```ts
// apps/admin/orval.config.ts
export default defineConfig({
  admin: {
    input: {
      target: '../../packages/api-contract/openapi.json',
      filters: { tags: [/^admin-/] },          // только API админки
    },
    output: {
      mode: 'tags-split',
      target: 'src/api/generated/endpoints',
      schemas: 'src/api/generated/model',
      client: 'react-query',
      httpClient: 'fetch',
      override: {
        mutator: { path: 'src/api/http-client.ts', name: 'httpClient' },
        query: { useQuery: true, signal: true },
      },
    },
  },
});
```

В конфиге сайта ставится обратный фильтр: теги `admin-*` исключаются.

## Структура

```text
apps/admin/src/
  routes/          маршруты TanStack Router (файловые)
  features/        users, listings, reports, import, catalog, rates, staff, audit
  components/      общие блоки админки: DataTable, FilterBar, ConfirmWithReason, StatusBadge
  api/             generated/ (orval), http-client.ts, query-client.ts

```

## Маршруты

| Маршрут | Раздел | Роль |
| --- | --- | --- |
| `/` | Сводка: очередь жалоб, несопоставленные объявления импорта, статус источников | модератор |
| `/users`, `/users/:id` | Пользователи | модератор |
| `/listings`, `/listings/:id` | Объявления | модератор |
| `/reports` | Жалобы | модератор |
| `/import/review` | Очередь ручной проверки импорта | модератор |
| `/import/sources`, `/import/runs/:id` | Источники и прогоны парсинга | администратор |
| `/catalog/brands`, `/catalog/brands/:id` | Марки, модели, поколения | администратор |
| `/catalog/categories` | Категории товаров и услуг с атрибутами | администратор |
| `/catalog/regions` | Регионы и города | администратор |
| `/catalog/custom-models` | Модели «Другая» из объявлений | администратор |
| `/rates` | Курсы валют | администратор |
| `/staff` | Сотрудники и роли | администратор |
| `/audit` | Журнал действий | администратор |

Меню показывает только доступные роли разделы. Это удобство, а не защита: права проверяет API.

## Правила интерфейса

- **Таблицы.** Фильтры, сортировка и страница хранятся в URL — ссылкой на выборку можно поделиться с коллегой.
- **Опасные действия** (блокировка, удаление, решение по жалобе) — через диалог `ConfirmWithReason`: причина обязательна, кнопка подтверждения красная.
- **Импорт.** Кнопка «Запустить» блокируется, пока прогон идёт. Статус прогона обновляется раз в 5 секунд (`refetchInterval`), пока статус `running`.
- **Справочники.** Названия редактируются сразу на RU и RO. После сохранения показывается, сколько объявлений будет переиндексировано.
- **Плотность.** Десктоп-first: админкой пользуются за компьютером. На телефоне достаточно, чтобы работали жалобы и блокировки.
- **Язык интерфейса** — русский и румынский, переключатель в шапке. Тексты — через i18n со словарями `ru.json` и `ro.json`, как на сайте; локаль хранится в cookie (в URL не нужна: админка не индексируется). Данные справочников показываются на обоих языках.
- **Без индексации:** `noindex` и закрытый `robots.txt`.

## Вход

- Та же страница входа по email-коду или Google, что и на сайте, но на домене админки.
- После входа приложение запрашивает `/api/v1/admin/me`. Ответ 403 — экран «Нет доступа».
- Сессия сотрудника живёт 12 часов, по истечении — повторный вход.
