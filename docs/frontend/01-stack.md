# Стек frontend

Сайт — Next.js с серверным рендерингом: каталог, карточки и профили должны индексироваться поисковиками и быстро открываться на мобильном интернете.

| Слой | Технология | Почему |
| --- | --- | --- |
| Фреймворк | Next.js 15 (App Router), React 19 | SSR и стриминг для SEO, серверные компоненты, оптимизация картинок |
| Язык | TypeScript 5, `strict` | Общие типы и схемы с backend |
| Стили | Tailwind CSS 4 + CSS-переменные токенов | Mobile-first утилиты, темы через переменные, нет лишнего CSS |
| UI-примитивы | Radix UI (через shadcn/ui, код в репозитории) | Доступные диалоги, выпадающие списки, табы; полный контроль над видом |
| Иконки | Lucide | Единый набор, tree-shaking |
| Генерация API-клиента | orval 7 (клиент `react-query`, HTTP через `fetch`) | Типы, функции запросов и хуки генерируются из OpenAPI backend, руками не пишутся. Подробно — [API-клиент](06-api-client.md) |
| Запросы и кэш | TanStack Query 5 | Кэш, повторные запросы, бесконечная лента, оптимистичные обновления, SSR-предзагрузка с гидрацией |
| Формы | React Hook Form + Zod (схемы из `packages/shared`) | Те же правила валидации, что на бэке |
| Локальное состояние | React state; Zustand — только для глобального UI-состояния | Без лишнего глобального стора |
| Фильтры в URL | nuqs | Состояние фильтров и сортировки живёт в URL: ссылкой можно поделиться, страница индексируется |
| Интернационализация | next-intl | RU и RO, локаль в URL, форматирование чисел, дат и валют |
| Тема | next-themes | Светлая и тёмная без мигания при загрузке |
| Чат | socket.io-client | Пара к Socket.IO на бэке |
| Свайпы (следующий этап) | @use-gesture + Motion | Жесты на телефоне, анимации карточек |
| Карусели фото | Embla Carousel | Лёгкая, свайпы на тач-экранах |
| Тесты | Vitest + Testing Library, Playwright, Storybook 8 | Юнит, e2e на мобильном и десктопном вьюпорте, каталог компонентов |
| Качество | ESLint, Prettier, TypeScript в CI, Lighthouse CI | Контроль Core Web Vitals |
| Аналитика | Собственные события по схеме из [метрик](../analytics/06-metrics.md) + веб-аналитика | Воронки и KPI |
| Ошибки | Sentry | Ошибки клиента и SSR |

Пакетный менеджер — pnpm, монорепо — Turborepo (общий с backend, см. [архитектуру backend](../backend/02-architecture.md)).
