# Доменная модель на фронте

Источник правды — [доменная модель backend](../backend/03-domain-model.md). Фронт не описывает сущности заново: типы генерируются из OpenAPI, а схемы форм берутся из `packages/shared`.

## Откуда берутся типы

| Что | Источник | Где лежит |
| --- | --- | --- |
| Ответы API (`ListingDto`, `UserPublicDto`, ...) | Генерация из OpenAPI (orval) | `shared/api/generated` |
| Схемы форм и запросов | Zod из `packages/shared` | Импорт `@clickauto/shared` |
| Enum'ы (валюты, статусы, типы объявлений) | `packages/shared` | Импорт `@clickauto/shared` |
| UI-модели (то, что удобно рисовать) | Маппинг из DTO | `entities/*/model` |

Генерированные типы не правятся руками. Если не хватает поля — меняется API.

## Основные сущности в UI

| Сущность | Где используется | Особенности отображения |
| --- | --- | --- |
| Listing (car / goods / service) | Ленты, карточки, избранное, профиль | Компонент выбирается по `type`. Импортированные — бейдж «Источник: 999.md» и ссылка |
| Money | Везде, где цена | Показывается в валюте автора. `null` + `negotiable` → «Договорная» |
| User (публичный) | Карточка, профиль, чат | Имя, `@username`, дата регистрации, аватар или инициалы |
| Me (текущий пользователь) | Шапка, кабинет, настройки | Язык и тема синхронизируются с сервером |
| FilterConfig | Панели фильтров | Описание полей с сервера, зависимости |
| Conversation, Message | Чат | Статусы сообщений: sending, sent, read, failed |
| Notification | Колокольчик в шапке | Счётчик непрочитанных |

## Форматирование

- Деньги: `formatMoney({amount, currency}, locale)` в `shared/lib/money`. Сумма приходит в минимальных единицах. Рубль ПМР — код `PRB` внутри системы, на экране — «руб.» / «rub.».
- Пробег: «120 000 км». Объём двигателя: из см³ в литры с одним знаком — «2,0 л».
- Даты публикации: «сегодня», «вчера», затем дата — через `Intl.RelativeTimeFormat`.
