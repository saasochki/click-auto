# Стайлгайд кода frontend

## Именование

| Что | Правило | Пример |
| --- | --- | --- |
| Файлы и папки | kebab-case | `listing-card.tsx`, `use-favorites.ts` |
| Компоненты | PascalCase, один публичный компонент на файл | `ListingCard` |
| Хуки | `use` + действие или сущность | `useToggleFavorite` |
| Обработчики | `handle` внутри компонента, `on` в пропсах | `onSelect={handleSelect}` |
| Булевы значения | `is`, `has`, `can` | `isHidden`, `canEdit` |
| Ключи i18n | `<фича>.<блок>.<смысл>` | `filters.price.from` |

## Компоненты

- Серверные компоненты по умолчанию. `'use client'` — только там, где есть состояние, эффекты или браузерные API, и как можно ниже по дереву.
- Пропсы — тип `Props` рядом с компонентом. Без `React.FC`.
- Компоненты из `packages/ui` не знают о домене: никаких `listing`, `user` в их пропсах.
- Стили — классы Tailwind, собранные через `cn()`. Варианты компонентов — через `cva`. Произвольные значения (`w-[37px]`) запрещены, только токены.
- Каждый публичный экспорт слоя — через `index.ts` слайса.

## Состояние

| Где состояние | Чем |
| --- | --- |
| Данные сервера | Хуки TanStack Query, сгенерированные orval, без копирования в локальный стейт. Прямой `fetch` в компонентах запрещён ([API-клиент](06-api-client.md)) |
| Фильтры, сортировка, вкладки | URL (nuqs) |
| Поля форм | React Hook Form |
| Глобальный UI (открыт ли чат-лист, тосты) | Zustand, минимально |
| Тема, язык, регион | Cookie + провайдеры |

## Формы

- Схема — Zod из `@clickauto/shared`, резолвер — `zodResolver`.
- Ошибки сервера (`errors[].field`) раскладываются по полям через `setError`.
- Кнопка отправки блокируется на время запроса. Повторная отправка защищена `Idempotency-Key`.

## Доступность

- Все интерактивные элементы доступны с клавиатуры, видимый фокус.
- Размер тач-цели — не меньше 44×44 px.
- Изображения объявлений — `alt` из заголовка: «Toyota Camry 2018, фото 1».
- Контраст текста — не ниже WCAG AA в обеих темах.
- Диалоги и листы — Radix: фокус-ловушка и закрытие по Esc.

## Тесты

| Уровень | Что тестируем | Инструмент |
| --- | --- | --- |
| Юнит | Форматтеры, маппинги DTO, хуки | Vitest |
| Компоненты | Поведение: клик, ввод, ошибки | Testing Library |
| Визуальные | Компоненты `packages/ui` в обеих темах | Storybook |
| E2E | Вход по коду, поиск с фильтрами, публикация объявления, отправка сообщения — на вьюпортах 375 и 1280 px | Playwright |

## Аналитика

- События — только через `track(event, params)` из `shared/lib/analytics`, названия и параметры — по [схеме метрик](../analytics/06-metrics.md).
- Новое событие сначала добавляется в схему, потом в код.

## Git

- Ветки, коммиты, релизы — по [gitflow](../gitflow.md).
- Коммиты — Conventional Commits: `feat(filters): add steering filter`.
- В PR со сменой UI — скриншоты мобильной и десктопной версии в обеих темах.
